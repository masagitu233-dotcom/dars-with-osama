========================================================================
DARS WITH OSAMA — PETUNJUK PENEMPATAN FILE VIDEO INTRO LOGO
========================================================================

Untuk memasang video intro logo asli Dars with Osama ke dalam proyek:

1. Salin/taruh file video intro Anda ke dalam folder ini:
   Path: public/video/intro-logo.mp4

2. Pastikan nama file adalah "intro-logo.mp4" (dengan huruf kecil dan tanpa spasi).

3. Pemutar video pada modal sambutan akan secara otomatis memuat dan memutar
   file /video/intro-logo.mp4 tersebut saat pengunjung membuka website.

Jika Anda menggunakan hosting/CDN eksternal (misalnya Firebase Storage atau Netlify Media),
Anda juga dapat memperbarui variabel INTRO_VIDEO_URL di file:
   src/config/videoConfig.ts
========================================================================
